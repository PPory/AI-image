## 公众号第 2 篇：新手教程文

### 标题

5 分钟上手 Pory.AI绘图：从选择风格到生成第一张图

### 正文

这篇文章只讲一件事：第一次打开 Pory.AI绘图，怎样顺利生成第一张图片。

### 第一步：填写 API Key

打开网页后，在左侧 API Key 区填写你的独立 Key，点击“保存 Key”。

Key 只保存在当前浏览器，不会显示在公开页面里。不要把 Key 发给别人，也不要截图公开。

### 第二步：先从风格库开始

新手不建议一开始自己从零写提示词。

右侧风格库里已经放好示例图和风格模板。你可以先挑一个接近目标的风格，比如：

- 做小红书封面：选封面或手账类风格。
- 做商品展示：选产品海报类风格。
- 做头像：选 3D 资料卡或 Q 版风格。
- 做菜单图：选美食海报类风格。

点进风格后，不会直接覆盖你的输入。保存 API Key 后可以查看完整提示词，确认要用，再点“使用此风格”。

### 第三步：替换主体

模板里会有 `{主体}` 这一类占位内容。你只需要把它换成你想生成的对象。

例子：

- 一个女孩。
- 一瓶柑橘气泡饮。
- 一份芝士牛肉汉堡。
- 一张学习打卡照片。
- 一套暗夜玫瑰主题美甲。

主体越具体，图片越容易接近你的想法。

### 第四步：选择模型

日常出图：选 GPT Image 2。  
高清封面和商品图：选 GPT Image 2 VIP。  
复杂参考图编辑：选 Nano Banana Pro。

分辨率会根据模型自动变化：

- GPT Image 2：只支持 1K。
- GPT Image 2 VIP：支持 2K / 4K。
- Nano Banana Pro：支持 1K / 2K / 4K。

### 第五步：生成并下载

点击“生成图片”后，保持页面打开。生成完成后，可以直接预览和下载。

如果失败，先看页面提示。如果提示违规，调整提示词后再试。如果是接口失败，可以把失败提示截图发给售后。

### 常见问题

图片不满意怎么办？  
先不要急着换模型，优先改主体、场景、光线、用途和风格关键词。

为什么不建议只写一句话？  
一句话通常太宽泛，模型不知道你要的是海报、照片、手账还是商品图。

应该先用哪个套餐？  
第一次建议体验包。确认能做出自己想要的图，再买更多额度。
