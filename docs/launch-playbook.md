# Pory.AI绘图 30 天开卖执行手册

## 目标

30 天拿到 30 个付费用户，验证真实需求、生成成功率和复购意愿。

核心闭环：

小红书案例种草 -> 公众号承接说明 -> 微信人工咨询 -> 人工收款 -> 发独立 API Key -> 售后和复购。

## 平台分工

### 小红书

定位：发现需求和收集意向。

内容只讲案例、方法和效果，不在正文或评论直接写“加微信购买 Key”。

推荐引导：

- 评论“模板”，领取完整提示词和体验入口。
- 想要同款步骤，可以看主页教程。
- 需要我帮你判断适合哪种图，可以评论你的用途。

避免话术：

- 加微信付款。
- 私信买 Key。
- 站外交易、便宜代充、包过审核。

### 公众号

定位：购买说明和信任承接。

公众号需要固定放 4 类内容：

- 产品入口。
- 套餐说明。
- 使用教程。
- 失败、退款、Key 使用规则。

公众号底部固定说明：

> API Key 只保存在当前浏览器。每个用户一个独立 Key，请勿共享、转发或公开。生成失败且上游未扣费时不消耗额度；图片生成成功但主观不满意，不退款、不补次数。禁止违法、侵权、色情、暴力、诈骗、仿冒证件等用途。价格和积分消耗可能随上游调整。

## 每日复盘

每天晚上记录 5 个数字：

1. 小红书发布篇数。
2. 小红书评论 / 收藏 / 私信数。
3. 公众号阅读数。
4. 咨询人数。
5. 成交人数和成交套餐。

每周只做一个判断：

- 哪个场景带来最多咨询。
- 哪个场景带来最多付费。
- 哪个问题导致用户犹豫。

## 阶段合格线

第 30 天前达到以下数据，说明可以继续做：

- 小红书 30 篇笔记累计带来 100 个有效访问或咨询。
- 公众号阅读转咨询率 5% 以上。
- 咨询到购买转化率 15% 以上。
- 首批用户生成成功率接近 100%。
- 退款和余额争议低于 5%。

如果没有达到，优先调整内容定位，不要急着加广告预算。
