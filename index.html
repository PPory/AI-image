购买后怎么用
  1. 复制微信号 qianaiyxs，联系购买额度包。
  2. 付款后会收到一个独立 API Key。
  3. 把 Key 填入本页，保存后即可生成和查询余额。
Key 保存在哪里

Key 只保存在当前浏览器的本地存储中。生成和查询余额时会发送给生图接口；点击“清除”后，本机保存的 Key 会被删除。

  • 每个用户一个独立 Key。
  • 请勿共享、转发或公开 Key；因共享导致额度消耗，不补偿。

失败与退款规则
  • 常见失败原因包括 Key 错误、余额不足、请求过快、接口繁忙或图片审核未通过。
  • 生成失败且上游未扣费时，不消耗用户额度。
  • 图片生成成功但主观不满意，不退款、不补次数。
  • 禁止违法、侵权、色情、暴力、诈骗、仿冒证件等用途。
