使用说明

如何开始

填写图片描述，选择模型、比例和分辨率，再填入自己的生图 API Key 后点击生成。

Key 保存在哪里

Key 只保存在当前浏览器的本地存储中。生成和查询余额时会发送给生图接口；点击“清除”后，本机保存的 Key 会被删除。

图片会不会保存

页面会在当前浏览器保存生成历史，方便回看结果。清空历史后，本地记录会被删除。

失败怎么办

常见原因包括 Key 错误、余额不足、请求过快、接口繁忙或图片审核未通过。请按页面提示处理。
